Get started

This manual is created and maintained with generative AI using the implementation and the live app as its basis.

  1. Open Fumen Mobile Fork.
  2. Choose a color in the editor, then tap or drag across the field to place blocks.
  3. Press + at the bottom to create the next page.
  4. Use the list icon at the bottom left to inspect all pages.
  5. Open Settings with the gear at the bottom right, and Import/Export, Reload, or Help from the menu (≡).
Mobile: long-pressing buttons provides additional actions. PC: configure keyboard shortcuts in User Settings.

The five screens

Reader

View completed fumen data. It is useful for moving between pages, playing the animation, and checking comments. Select the pencil icon to move to Edit.

Edit

Edit the field, pieces, comments, and pages. Most work starts on this screen.

List

Review every page as a card. It is useful for reordering pages, editing comments, and exporting images or URLs.

Tree

Branch from the same position into multiple sequences. It is useful for organizing candidate moves, setups, and completions.

TETR.IO Replay

Play back a TETR.IO multiplayer replay (.ttrm), evaluate moves with AI, and take any position into Edit.

While Tree mode is enabled, switch between List and Tree with the list and tree buttons in the overview's bottom bar. When Tree mode is enabled, page order follows the tree structure. On PC, List or Tree can also appear in a side panel beside Edit.

Edit the field

Draw with PAINT

Pen

Choose from seven colors, black, or gray, then tap or drag to place blocks. Long-press a color to spawn its corresponding piece and switch to PIECE.

Erase

Remove blocks. When Delete spawn mino when an eraser drag passes over it is enabled, the drag also removes SPAWN pieces it passes over.

Fill and Fill row

Fill a connected area or one row with the selected color. Choose black (empty) to erase the same area.

COMP

Select four cells to infer a piece from its shape and confirm it with the matching color. Long-press to clear colored blocks and SPAWN pieces while leaving gray blocks.

Mino ⇄ blocks

Use TO PAINT in the context tray to turn a SPAWN mino into four blocks at the same position. Without a SPAWN mino, press TO MINO and pick one of the highlighted shapes to turn it back into a mino. While picking, the button reads CANCEL; press it again to stop. The action is also available as Spawn mino / blocks in UTILS and as a key assignment (B by default). Paint blocks do not line-clear through Lock.

Play pieces in INPUT

  • INPUT: Open it from INPUT on the rail. Operate the queue's CURRENT piece; a hard drop moves to the next page and spawns the next CURRENT. NEXT is listed upward from the nearest piece.
  • HOLD / NEXT: Select them to open Piece queue settings. The queue is stored in the page comment as data such as #Q=[](I)OTLJSZ. Closing the dialog promotes the first NEXT piece when CURRENT is empty.
  • Placement statistics: Below HOLD, INPUT shows the latest line clear or spin plus B2B, Combo, PIECES, LINES, and PC. Pages taken from a TETR.IO replay also show ATTACK, CANCEL, and SENT. Short screens show fewer rows.
  • AI Guide: Turn it on or off with the button above HOLD. See The AI Guide in INPUT.
  • Replay: The button above NEXT opens the TETR.IO Replay screen.
  • ∞ 7bag: Automatically refills the queue with randomized seven-piece bags. 7bag grey directly below it is available only while infinite 7-bag is on.
  • 7bag grey: Groups every seven placements into one page and grays the completed bag's field. It hides ordinary comments while keeping queue and progress as editor data. INPUT workspace branches are protected in Tree mode.
  • RESET: Resets the field and CURRENT. With infinite 7-bag on, it starts over with a new random queue.

Reuse a region with SELECT

  1. Choose SELECT and drag from the start point to the end point on the field.
  2. Choose Copy, Cut, Rotate left, Rotate right, or Mirror from the context tools.
  3. Copied or cut regions are saved in an empty palette slot. Select that slot, then tap the field to stamp it.
  4. Long-press a slot to pin the part and keep it saved. The switch at the bottom of the palette controls whether empty cells pass through when stamping.

UTILS and FLAGS

  • Apply to this page: Mirror, Convert to gray, Delete non-gray (also removes the SPAWN piece), Spawn mino / blocks, and Clear.
  • Apply to all pages: Mirror all pages, Replace comments, and Reset all comments. Reset all comments preserves tree data and can be undone.
  • Delete pages: <-Clear deletes the pages before the current page, and Clear-> deletes the pages after it.
  • Editing modes: Slide opens a tray for moving the field (Up + gray, Up, Left, Right, Down, Done). Comment opens a tray with Blank and Inherit.
  • TETR.IO Replay: Open TETR.IO replay moves to the replay screen.
  • FLAGS: Toggle Key page / Reference page, Lock, Rise, and Mirror flag. On a page with Lock on, line clears are applied when moving to the next page.
  • Panels: Drag the header to move a panel. An item normally closes UTILS. Enable Keep the UTILS menu open to keep choosing items while using the field.

Pages and comments

Move between pages

Use the left and right buttons at the bottom. Long-press to jump to the first or last page.

Insert in the middle

Use + or INSERT even when a next page already exists. The new page is inserted between the current and next pages.

Undo and redo

Undo or redo the latest edit with the buttons at the bottom. While operating a NEXT queue in INPUT, Undo and Redo move across one consumed piece at a time. History is preserved when editing across screen modes.

Comments

Write explanations or NEXT queue data in the field below the board. In List, edit comments while viewing all pages; replace text across all pages from UTILS.

Page rotation

Set a retained page count to drop the oldest page numbers when additions exceed the limit. Set 0 for no limit.

First-page information: Some information, such as the color setting, applies to the entire fumen. It carries forward automatically even when the first page is replaced.

Organize pages in List

Open it with the list icon at the bottom left of the editor.

  1. Select a card once to make it active, then select the active card again to move to its Edit screen.
  2. Use #page number links to move to a page. In the side panel, only the Edit field on the right updates.
  3. Drag a card to reorder pages. Reordering is disabled while Tree mode is enabled.
  4. Edit a comment directly in its text area. Use Replace comments in UTILS to replace text across all pages.
  5. The bottom bar holds Back to Edit, the Tree mode switch, the List and Tree buttons (only in Tree mode), UTILS, Import, Export, Settings, and Menu. Undo/Redo is at the bottom left, and View settings is the floating button at the bottom right.
  6. UTILS: Without leaving List, mirror, gray out, or clear the current page, mirror all pages, replace or reset comments, delete pages, or open TETR.IO Replay.
  7. View settings (the bottom-right button) includes the Trim top blank switch, a Zoom slider, and All settings. The slider snaps near 100%, and tapping the percentage returns to 100%. Use Ctrl + the mouse wheel to zoom on PC.

Branch with Tree

  1. Turn on the switch next to the tree icon in the List bottom bar.
  2. Select the tree view button in the bottom bar to switch to Tree.
  3. Select the node to branch from, then use the colored buttons to create the next sequence.

  • Dragging: Start a drag from the Drag to move grip below the node.
  • Move/Delete: Choose Node only, Node & descendants, or Descendants only from the bottom-left chip. The same scope applies to moving and deleting.
  • Descendants only: Keep the node and move or delete only its descendants. The green button is available when there is one direct child. Only when the destination is a leaf node can multiple child subtrees be moved while keeping their original order.
  • Delete: Select the Delete page icon at the top right of a node. Restore it with Undo in the notification after deletion. The last page cannot be deleted.
  • Select a node: Select a node once to make it active, then select the active node again to move to its Edit screen.
  • Disable Tree mode: A confirmation dialog appears because the tree structure will be deleted. You can undo the change.
  • Add a parent tree: The dashed plus card creates an independent root that is not connected to the existing branches. Use it to manage another set or loop in the same fumen.
  • View settings: The bottom-right button toggles Trim top blank and Gray out with + button, and sets the zoom. Gray out with + button grays out the blocks left after line clears when + creates a page.
  • AI: The blue AI button at the bottom right opens the AI menu from the selected node.
  • From root to selected page: When exporting, you can limit the output to the pages from the root through the selected node.
Important: Tree data is stored in the first page comment as #TREE=.... Do not delete or rewrite this string while using Tree. Other fumen tools may display it as an ordinary comment.

The PC side panel

On PC, show List or Tree on the left while keeping Edit open. This is useful for checking all pages or branches while editing the field.

  1. Select Show side panel at the top of the screen. You can also toggle it from User Settings > List & Tree > Show side panel (PC).
  2. Choose the List or Tree tab.
  3. Select a card or node and edit the field on the right. Comments and the current page stay synchronized.
  • List tab: Move between pages, edit comments, and drag to reorder. Reordering is disabled in Tree mode.
  • Tree tab: Turn on Tree mode with Enable tree mode, add continuations and branches, duplicate or delete nodes, choose the Move/Delete scope, and move between pages.
  • Panel buttons: Undo/Redo is at the bottom left (with the Move/Delete chip in the Tree tab), view settings at the bottom right, and in the Tree tab the AI button sits above view settings. View settings has the same zoom slider as full-screen mode.
  • Resize: Drag the divider at the right edge of the panel. Double-click the divider to return to the automatic width.
  • Availability: This is a PC feature. The panel hides automatically below 1024px and reappears when the viewport is wide enough.

Analyze with AI

The AI menu offers two engines: Cold Clear, and Sold Slear, a bot in development for TETR.IO Season 2 rules.

  1. Select AI on the Edit rail, or the blue AI button in Tree.
  2. Set Hold, Current, Next, B2B, and Combo to match the current situation.
  3. Review the search settings and run the search that matches your goal.

Three searches

Sequence Search

Add AI moves through the end of the configured queue as a chain of pages, then switch to Tree. Use it when you first want to see one complete line.

Branch Search

Add the top candidates to Tree as branches. Use it to compare several possible moves.

Get Score

Run it on a page where the queue's CURRENT piece has been placed on the ground, and the AI evaluates that placement. The result is written to the comment as score=…, and the editor returns to PAINT afterward.

Running a search turns on Tree mode automatically.

Enter a queue

  • Select the Hold, Current, or Next field, then enter pieces with the I O T L J S Z buttons. Changing Current respawns the piece on the field.
  • Clear removes the currently selected field.
  • +1bag appends one bag of all seven pieces to Next.
  • B2B: Set the current Back-to-Back state. Combo: Set the current Combo (REN) count.
  • Edits are written to the page comment when you press Close or start a search, and they can be undone. On a page whose comment is not a queue, choose Clear comment and edit queue first.

While a search is running, use Stop search from the same menu. Progress is also shown on the AI button. Settings cannot be changed during a search.

Sold Slear

  • Select the engine name in the menu heading (Cold Clear ⇄) to switch to Sold Slear. The chosen engine is also used by the INPUT AI Guide and the replay AI analysis.
  • It is a development bot that assumes SRS+, 180° rotation, and all-spin. When the kick table is not SRS+, the menu warns that some suggested moves may not be reachable.
  • It needs at least one NEXT piece. Get Score shows the placement's rank among the candidates in a notification.

The AI Guide in INPUT

  • In INPUT, select AI Guide above HOLD to turn it on or off. When it is on, the best move for CURRENT appears on the field as translucent blocks with a dashed outline.
  • The button shows its state: OFF, Waiting, Thinking…, or Showing. It recalculates after every placement, and a guide that is already showing stays in place when you Hold until the piece locks.
  • When the guide cannot be used, a reason such as No queue, Wrong piece, Page flags, Need NEXT, Clear lines, No move, Previewing, or AI error appears in red.
  • It uses the AI menu's engine, Hold usage, NEXT limit, think time, and other settings, together with B2B and Combo from the comment.
When a search takes too long: reduce Think time, Top candidates, and queue length. Branch Search can grow rapidly as these settings are combined.

Import, export, and sharing

Load from clipboard

Replace all current pages with the loaded content. Confirm that replacement is intended before using it.

Insert from clipboard

Add loaded content to the end of the current fumen. Use it when you want to keep the existing fumen and append to it.

Copy data

Copy fumen data (v115), the share URL, or tetgram raw data.

PNG / GIF

Save the page list as a still image or animation, with or without page numbers and comments.

Open URL

Open the current content via the share URL, Fumen Editor, Fumen for mobile, or tetgram.

TETR.IO Replay

Load a .ttrm file, play the match back, and take any position into Edit.

Import/Export

  • Import: Load from clipboard replaces the whole fumen, while Insert from clipboard appends to the end. tetgram RawData JSON is detected automatically. On PC, a short Ctrl + V press inserts, while holding it for at least 500ms loads the data.
  • Pages to export: In Tree mode, choose All pages or From root to selected page. The choice applies to every export action in the tab.
  • Copy data: Copy fumen data, the share URL, or tetgram raw data (including the tree layout).
  • Save image: Choose PNG or GIF. Use Show page numbers and Show comments to choose what the image includes, and GIF page interval (100–10000 ms) to set how long each page is shown in a GIF. With All pages selected in Tree, PNG saves the tree diagram.
  • Open URL: Open the share URL, Fumen Editor, Fumen Editor (LIST), Fumen for mobile, or tetgram. URLs opened in tetgram do not include the tree layout.
  • Short URL: When on, the TinyURL creation page is used when opening share, external, and tetgram URLs.

Common import formats

  • Fumen Mobile Fork, fumen-for-mobile, and PC fumen URLs
  • fumen v115 or later strings
  • tetgram RawData JSON
  • Field images copied to the clipboard
Tips for importing images: Select the field along its grid lines and copy it to the clipboard as an image before inserting it. A complete 20×10 field is most reliable, but images with fewer rows can also be loaded.

Share URLs include pages and tree data. When a URL is too long, enable Short URL in Import/Export.

Play back a TETR.IO replay

  1. Select Open TETR.IO replay in UTILS, or the Replay button in INPUT.
  2. Choose a .ttrm file with Select file, or drop the file on the screen.
  3. Choose Your side and a round under Rounds, then press Play this round.
  • Playback: The previous and next buttons step through your pieces and stop just before each one locks. Play/pause, jump to the start or end, change the speed (x0.25–x4), or move to any time on the timeline. On PC, ←/→ step through pieces and Space plays or pauses. Turn on the lock button to disable jumping to the start or end.
  • Display: Both players' HOLD and NEXT, B2B and Combo, the latest clear, and pps, apm, app, vs, and area are shown. Hide opponent hides the opponent's board, and ⇄ Swap swaps your side and the opponent.
  • Garbage: The gauge left of each board shows incoming attacks, and the row below the board shows the rows that will rise and their holes. Timeline marks are red for tanked and green for cancelled garbage. In a lost round, the cause of loss and a Go to that moment link appear.
  • AI analysis: Choose a think time and press Analyze this round to have the AI evaluate each of your moves. Longer bars in the graph mean a bigger gap from the best move; click the graph to jump to that move. Match rate, mean loss, max loss, and Biggest losses are also shown. Switch between Cold Clear and Sold Slear with the engine name in the heading.
  • Take a position into Edit: Open this point in Editor inserts the current position as a new page after the current page and opens it in INPUT. HOLD, CURRENT, and NEXT go into the comment's queue, and B2B, Combo, and incoming garbage carry over as battle state, so you can keep playing in INPUT.
  • Supported files: Two-player .ttrm replays (League and private rooms) up to 8 MB per file, played one round at a time. Rounds that cannot be reproduced are marked Not reproducible and cannot be selected.

AI analysis results and the carried-over battle state are not saved and are not included in share URLs.

Troubleshooting

Pages cannot be reordered

List drag-reordering is disabled in Tree mode. Move nodes in Tree while preserving the tree structure, or disable Tree mode.

The AI cannot run

Check that the Queue is not empty. Get Score requires a page where the CURRENT piece has been placed on the ground. Another search cannot start while a search or the replay AI analysis is running.

The AI Guide does not appear

Check the reason shown on the AI Guide button. The guide is not shown when there is no queue comment, when the piece on the field differs from CURRENT, or when a completed line has not been cleared.

A replay cannot be loaded

Check that the file is a two-player .ttrm replay. When loading fails, the reason is shown on the screen.

An image cannot be imported

Confirm that the image is on the clipboard and follows the field grid. Reduce margins and text, then select the field again.

The tree disappeared

Check that #TREE=... remains in the first page comment. If you saved or shared after deleting it, the original tree data may not be recoverable.

Settings were reset

Settings are saved in the browser. Clearing cache or site data, using another browser, or using another device does not carry them over.

The shared result looks different

Open the share URL again and check the kick table, Trim top blank, and Tree mode settings.
