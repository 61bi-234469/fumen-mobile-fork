Fumen Mobile Fork
ユーザーマニュアル

テト譜の作成、ページ整理、分岐検討、AIによる盤面分析、TETR.IOリプレイの再生をスマートフォンとPCで行えます。

English

はじめに画面編集ページリストツリーサイドパネルAI取り込み・書き出し設定便利な操作困ったとき

まず使ってみる

このマニュアルは、実装と実画面を基に生成AIを利用して作成・メンテナンスしています。

  1. Fumen Mobile Forkを開く。
  2. Edit画面で色を選び、盤面をタップまたはドラッグしてブロックを置く。
  3. 下部の + で次のページを作る。
  4. 左下のリストアイコンで全ページを確認する。
  5. 右下の歯車で設定、メニュー（≡）から取り込み・書き出し、Reload、Helpを開く。
スマートフォン：ボタンの長押しに追加操作があります。PC：ユーザー設定でショートカットキーを設定できます。

5つの画面を使い分ける

Reader

完成したテト譜を閲覧します。前後ページへの移動、アニメーション再生、コメント確認に向いています。鉛筆アイコンでEditへ移動します。

Edit

盤面、ミノ、コメント、ページを編集します。通常の作業はこの画面から始めます。

List

全ページをカード形式で並べて確認します。並べ替え、コメント編集、画像やURLの出力に向いています。

Tree

同じ局面から複数の手順へ分岐させます。候補手、セットアップ、補完の整理に向いています。

TETR.IO リプレイ

TETR.IOの対戦リプレイ（.ttrm）を再生し、AIで手を評価して、好きな局面をEditへ取り出します。

ツリーモードが有効なときは、一覧画面の下部バーにあるリスト／ツリーのボタンでListとTreeを切り替えます。ツリーを有効にすると、ページ順はツリー構造に合わせて管理されます。PCでは、Editの左側にListまたはTreeをサイドパネルとして表示できます。

盤面を編集する

PAINTで描く

ペン

7色・黒・灰色から選び、タップまたはドラッグでブロックを置きます。色を長押しすると対応するミノを出現させ、PIECEへ切り替わります。

消しゴム

ブロックを消します。設定の消しゴムのドラッグでSPAWNミノも削除するが有効なら、ドラッグが通過したSPAWNミノも削除します。

塗りつぶし・行を塗る

連続した範囲または1行を選択色で塗ります。黒（空）を選ぶと同じ範囲を消去します。

COMP

マスを4つ選び、形からミノを推定して対応色で確定します。長押しすると色付きブロックとSPAWNミノを消し、灰色ブロックを残します。

ミノ ⇄ ブロック

操作トレイのブロック化でSPAWNミノを同じ位置の4ブロックへ変換します。SPAWNミノがないときはミノ化を押し、強調表示された形から1つ選ぶとミノに戻せます。選択中のボタンはやめるになり、もう一度押すと中止します。UTILSのSPAWNミノ ⇄ ブロックやキー割り当て（既定はB）からも実行できます。ブロック化後は固定によるライン消去は行われません。

PAINT・PIECE・INPUT・SELECTを切り替える

モード主な操作
PAINTペン、消しゴム、塗りつぶし、行を塗る、ブロック化／ミノ化。パレットはブロック色として表示されます。
PIECEパレットからミノを出現させ、Hold、ハードドロップ、左右移動、ソフトドロップ、左右回転を操作します。SRS+では180°回転も使えます。左右移動の長押しはDAS・ARRの設定に従って連続移動します。パレットの削除でミノを消し、RESPAWNで出し直します。PIECE中の + は、次ページを作るときに盤面をグレー化します。
INPUTキューのCURRENTを直接操作します。HOLD・NEXT、配置統計、AIガイド、リプレイボタンを表示します。
SELECT盤面をドラッグして矩形選択し、コピー、切り取り、左回転、右回転、反転を行います。

選択中のPAINTまたはSELECTをもう一度押すと、盤面下の操作トレイを表示／非表示にできます。非表示の間はせり上がり行を編集できます。トレイが収まらないときは文字をアイコンにまとめ、それでも収まらなければ横スクロールできます。

INPUTで実戦のように操作する

  • INPUT：レールのINPUTから開きます。キューのCURRENTを操作し、ハードドロップすると次のページへ進んで次のCURRENTが出現します。NEXTは近いピースから上へ並びます。
  • HOLD / NEXT：選ぶとピースキュー設定が開きます。キューはページコメントへ #Q=[](I)OTLJSZ のような形式で保存されます。閉じるときにCURRENTが空ならNEXTの先頭がCURRENTへ移ります。
  • 配置統計：HOLDの下に直前のライン消去・Spinと、B2B、Combo、設置、消去、PCを表示します。TETR.IO リプレイから取り出したページでは、攻撃・相殺・送信も表示します。画面の高さに応じて項目は省略されます。
  • AIガイド：HOLDの上のボタンでオン／オフします。詳しくはINPUTのAIガイドを参照してください。
  • リプレイ：NEXTの上のボタンでTETR.IO リプレイ画面を開きます。
  • ∞ 7bag：ランダムな7種1組のキューを自動補充します。オンの間だけ、直下の7bag greyを切り替えられます。
  • 7bag grey：7個ごとにページをまとめ、確定したbagの地形をグレー化します。通常コメントは表示せず、キューと進捗は編集用データとして保持します。ツリーモードではINPUT用の作業分岐を保護します。
  • RESET：盤面とCURRENTをリセットします。∞ 7bagがオンのときは、新しいランダムキューで最初から始めます。

SELECTで範囲を再利用する

  1. SELECTを選び、盤面上を始点から終点までドラッグする。
  2. 操作トレイからコピー、切り取り、左回転、右回転、反転を選ぶ。
  3. コピーまたは切り取りした範囲はパレットの空き枠へ保存されます。その枠を選び、盤面をタップしてスタンプします。
  4. 枠を長押しするとパーツをピン留めして保存できます。パレット最下段のスイッチで、スタンプ時に空セルを透過するかを切り替えます。

UTILSとFLAGS

  • このページに適用：反転、グレー化、グレー以外削除（SPAWNミノも消去）、SPAWNミノ ⇄ ブロック、クリア。
  • 全ページに適用：全ページ反転、全ページコメント置換、全ページコメントリセット。コメントリセットはツリーデータを維持し、Undoできます。
  • ページ削除：<-Clearで現在ページより前、Clear->で現在ページより後のページを削除します。
  • 編集モード：スライドは盤面を上下左右へ動かすトレイ（上へ + グレー、上、左、右、下、完了）を、コメントは空にする・引き継ぐのトレイを開きます。
  • TETR.IO リプレイ：TETR.IO リプレイを開くでリプレイ画面へ移動します。
  • FLAGS：キーページ／参照ページ、固定、せり上がり、反転フラグを切り替えます。固定がオンのページでは、次ページへ進むときにライン消去を反映します。
  • パネル：見出しをドラッグして移動できます。項目を選ぶと閉じます。ユーザー設定のUTILSメニューを開いたままにするを有効にすると、盤面を操作しながら続けて項目を選べます。

ページとコメントを管理する

前後へ移動

下部の左右ボタンで移動します。長押しすると最初または最後のページへジャンプします。

途中へ追加

次ページがある状態でも + や INSERT を使えます。新しいページは現在ページと次ページの間に入ります。

元に戻す

下部のUndo/Redoで直前の編集を戻したりやり直したりできます。INPUTでNEXTキューを操作しているときは、ミノ1個分の操作をまとめて戻したりやり直したりできます。画面モードをまたぐ編集でも履歴が維持されます。

コメント

盤面下の欄へ説明やNEXTキューを書けます。Listでは全ページを見ながら編集でき、UTILSから全ページの文字列を一括置換できます。

ページローテーション

保持ページ数を設定すると、ページ追加時に上限を超えた古いページ番号から自動で削除します。0は上限なしです。

先頭ページの情報：色の設定など一部の情報はテト譜全体に適用されます。先頭ページが入れ替わる操作でも、これらの情報は自動で引き継がれます。

Listで全ページを整理する

Edit画面左下のリストアイコンから開きます。

  1. 1回選ぶとそのカードがアクティブになり、アクティブなカードをもう一度選ぶとそのページのEditへ移動します。
  2. #ページ番号からも対象ページへ移動できます。サイドパネルでは画面を切り替えず、右側のEditだけが更新されます。
  3. カードをドラッグするとページを並べ替えられます。ツリーモード中は並べ替えできません。
  4. コメント欄はその場で編集できます。UTILSの全ページコメント置換で全ページの文字列を一括置換できます。
  5. 下部バーには、Editへ戻る、ツリーモードのスイッチ、リスト／ツリー切替（ツリーモード中のみ）、UTILS、取り込み、書き出し、設定、メニューが並びます。Undo/Redoは左下、表示設定は右下のフローティングボタンです。
  6. UTILS：Listを離れずに、現在ページの反転・グレー化・クリア、全ページ反転、全ページコメント置換・リセット、ページ削除、TETR.IO リプレイを実行できます。
  7. 表示設定（右下のボタン）には上部の空白行を省略、ズームのスライダー、すべての設定があります。スライダーは100%付近で自動的にスナップし、%表示をタップすると100%に戻ります。Ctrl+ホイールでも拡大縮小できます。

Treeで手順を分岐管理する

  1. Listの下部バーにあるツリーアイコン横のスイッチをオンにする。
  2. 下部バーのツリービューのボタンを選び、Treeへ切り替える。
  3. 起点にしたいノードを選び、色付きボタンで続きを作る。

PCのサイドパネルを使う

PCではEditを開いたまま、左側にListまたはTreeを表示できます。盤面を編集しながらページ全体や分岐を確認したいときに便利です。

  1. 画面最上部の サイドパネルを表示 を選ぶ。ユーザー設定の「リスト/ツリー」→「サイドパネルを表示（PC）」からも切り替えられます。
  2. リストまたはツリータブを選ぶ。
  3. カードやノードを選び、右側の盤面を編集する。コメントと現在ページも相互に同期します。
  • リストタブ：ページ移動、コメント編集、ドラッグ並べ替えができます。ツリーモード中は並べ替えできません。
  • ツリータブ：ツリーモードを有効にするでツリーを有効化し、ノード追加・分岐・複製・削除、移動・削除範囲の選択、ページ移動ができます。
  • パネル内のボタン：左下にUndo/Redo（ツリータブでは移動・削除範囲のチップも）、右下に表示設定、ツリータブでは表示設定の上にAIボタンがあります。表示設定にはフル画面と同じズームスライダーがあります。
  • 幅の変更：パネル右端の区切り線をドラッグします。区切り線をダブルクリックすると自動幅へ戻ります。
  • 表示条件：PC用機能です。画面幅が1024px未満になると自動的に隠れ、幅を戻すと再表示されます。

AIで盤面を分析する

AIメニューでは、Cold Clearと、TETR.IO Season 2のルール向けに開発中のSold Slearの2つのエンジンを使えます。

  1. EditのレールのAI、またはTreeの青いAIボタンを選ぶ。
  2. Hold、Current、Next、B2B、Comboを現在の状況に合わせる。
  3. 探索条件を確認し、目的に合う探索を実行する。

3つの探索

連続探索

設定したキューの最後までAIの手順を続きのページとして追加し、Treeへ切り替えます。まず結果を1本見たい場合に向いています。

分岐探索

上位候補を分岐としてTreeへ追加します。複数の候補手を比較したい場合に使います。

スコア取得

キューのCURRENTと同じミノを接地させたページで実行し、その配置をAIに評価させます。結果はコメントへ score=… として書き込まれ、終了後はPAINTに戻ります。

探索を実行すると、ツリーモードが自動で有効になります。

キューの入力

  • Hold、Current、Nextの欄を選び、I O T L J S Z ボタンで入力できます。Currentを変えると盤面のミノも出し直されます。
  • クリアは現在選択中の欄を消します。
  • +1bagはNextへ7種1組を追加します。
  • B2B：現在のBack-to-Back状態を指定します。Combo：現在のCombo（REN）数を指定します。
  • 入力内容は閉じるまたは探索開始時にページコメントへ書き込まれ、Undoできます。コメントがキュー形式でないページでは、コメントを削除してキューを編集するを選んでから入力します。

探索設定

設定意味目安
Hold使用探索中にHoldを許可する（Cold Clear）実戦に合わせるならオン
NEXT制限AIへ渡す既知NEXT数を制限する（Cold Clearは0〜30、Sold Slearは1〜30）見えているNEXTだけで比較したいときに使用
思考時間1手あたりの探索時間を100ms・200ms・500ms・1s・2sから選ぶ（Cold Clear）まず1s。速度優先なら短く、精度優先なら長く
重み評価戦略をDefaultまたはFastから選ぶ（Cold Clear）。FastはTスピンより掘りやRENを選びやすい通常はDefault
Speculate既知キューより先のピースを推測して探索する（Cold Clear）NEXTが短い状況で候補を広げる
探索量標準（固定量で毎回同じ手を返す）または100〜2000msから選ぶ（Sold Slear）まず標準
上位候補数分岐探索で残す候補数（Cold Clearは1〜20、Sold Slearは1〜16）候補を増やすほど処理と結果量が増える

探索中は同じメニューの探索停止で中断できます。進行状況はAIボタンにも表示されます。探索中は設定を変更できません。

Sold Slear

  • メニュー見出しのエンジン名（Cold Clear ⇄）を選ぶとSold Slearに切り替わります。選んだエンジンは、INPUTのAIガイドとリプレイのAI解析でも使われます。
  • SRS+・180°回転・all-spinを前提にした開発中のボットです。キックテーブルがSRS+以外のときは、提案手に到達できない場合があることが表示されます。
  • NEXTが1個以上必要です。スコア取得では、候補の中での順位を通知で表示します。

INPUTのAIガイド

  • INPUTでHOLDの上のAIガイドを選ぶとオン／オフが切り替わります。オンにすると、CURRENTの最善手を半透明のブロックと点線枠で盤面に表示します。
  • ボタンにはOFF、待機中、計算中…、表示中の状態が表示されます。1手置くたびに再計算し、Holdしても表示中のガイドは固定するまで同じ位置に残ります。
  • 使用できない局面では、キューなし、ミノ不一致、フラグ非対応、NEXT不足、消去待ち、候補なし、プレビュー中、AIエラーなどの理由が赤字で表示されます。
  • AIメニューのエンジン、Hold使用、NEXT制限、思考時間などの設定と、コメントのB2B・Comboを使って計算します。
探索が長いとき：思考時間、上位候補数、キュー長を小さくしてください。特に分岐探索は設定の組み合わせで探索数が大きく増えます。

取り込み・書き出しと共有

クリップボードから読み込む

現在の全ページを読み込み内容で置き換えます。置き換えてよいことを確認してから実行してください。

クリップボードから挿入

現在のテト譜の末尾へ読み込み内容を追加します。今あるテト譜を残してつなげたい場合に使います。

データをコピー

テト譜データ（fumen v115）、共有URL、tetgram用rawデータをコピーします。

PNG / GIF

ページ一覧を静止画またはアニメーションとして保存します。ページ番号とコメントの表示を選べます。

URLで開く

共有URL、連続テト譜エディタ、Fumen for mobile、tetgramで現在の内容を開きます。

TETR.IO リプレイ

.ttrmファイルを読み込んで対戦を再生し、任意の局面をEditへ取り出します。

Import/Export

  • 取り込み：クリップボードから読み込むは全体を置き換え、クリップボードから挿入は末尾へ追加します。クリップボード上のtetgram RawData JSONも自動判定します。PCではCtrl+V（Macは⌘+V）の短押しが挿入、500ms以上の長押しが読み込みと同じ動作です。
  • 書き出すページ：ツリーモード中は、すべてまたはルートから選択ページまでを選べます。選んだ範囲は、書き出しタブ内のすべての操作に適用されます。
  • データをコピー：テト譜データ、共有URL、tetgram用rawデータ（ツリー構造のリスト配置ごと）をコピーします。
  • 画像を保存：PNGとGIFを選べます。ページ番号を表示とコメントを表示で画像に含める情報を選び、GIFページ送り間隔（100〜10000ms）でGIFの1ページあたりの表示時間を設定します。Treeで「すべて」を選んだPNGはツリー図として保存されます。
  • URLで開く：共有URL、連続テト譜エディタ、連続テト譜エディタ(LIST)、Fumen for mobile、tetgramで開きます。tetgramで開くURLにはツリーのリスト配置は含まれません。
  • 短縮URL：オンにすると、共有URL・外部サイト・tetgramを開くときにTinyURL作成ページを使用します。

読み込める主な形式

  • Fumen Mobile Fork、fumen-for-mobile、PC版テト譜のURL
  • fumen v115以降の文字列
  • tetgram RawData JSON
  • クリップボードにコピーした盤面画像
画像読み込みのコツ：マス目に沿って盤面を範囲選択し、画像としてクリップボードへコピーしてから挿入します。20×10の盤面全体が最も安定しますが、縦方向を省略した画像も読み込めます。

共有URLにはページやツリーデータが含まれます。URLが長い場合は、Import/Exportの短縮URLを利用できます。

TETR.IO リプレイを再生する

  1. UTILSのTETR.IO リプレイを開く、またはINPUTのリプレイボタンを選ぶ。
  2. ファイルを選択で.ttrmファイルを選ぶ（ドロップでも読み込めます）。
  3. 自陣プレイヤーとラウンドを選び、このラウンドを再生を押す。
  • 再生：前後ボタンで自陣の手番ごとに、固定する直前の局面で止まります。再生／一時停止、先頭・末尾、速度（x0.25〜x4）、タイムラインで任意の時点へ移動できます。PCでは←/→で手番送り、Spaceで再生／一時停止します。錠前ボタンをオンにすると先頭・末尾への移動を無効にします。
  • 表示：両者のHOLD・NEXT、B2B・Combo、直前の消去、pps・apm・app・vs・areaを表示します。相手を隠すで相手の盤面を隠し、⇄ 入替で自陣と相手を入れ替えます。
  • ガベージ：盤面左のゲージに受けた攻撃、盤面下にせり上がる行と穴の位置を表示します。タイムラインの印は赤が被弾、緑が相殺です。負けたラウンドでは死因とその地点へのリンクを表示します。
  • AI解析：思考時間を選んでこの試合を解析するを押すと、自陣の各手をAIが評価します。グラフは棒が長いほど最善手との差が大きく、クリックするとその手へ移動します。一致率、平均損失、最大損失と大きく損した手も表示します。見出しのエンジン名でCold ClearとSold Slearを切り替えられます。
  • Editへ取り出す：この地点を Editor で開くを押すと、現在の局面を現在ページの直後に新しいページとして挿入し、INPUTで開きます。HOLD・CURRENT・NEXTはコメントのキューへ、B2B・Combo・受けている攻撃は対戦状態として引き継がれ、INPUTで続きを操作できます。
  • 対応範囲：2人対戦の.ttrm（リーグ、プライベートルーム）に対応します。1ファイル8MBまでで、1ラウンドずつ再生します。再現できないラウンドは「再現不可」と表示され、選択できません。

AI解析の結果と引き継いだ対戦状態は保存されず、共有URLにも含まれません。

困ったとき

ページを並べ替えられない

ツリーモード中はListのドラッグ並べ替えが無効です。ツリー構造を維持したままTreeでノードを移動するか、ツリーモードを解除してください。

AIを実行できない

Queueが空でないか確認してください。スコア取得では、CURRENTと同じミノを接地させたページが必要です。探索中やリプレイのAI解析中は、別の探索を開始できません。

AIガイドが出ない

AIガイドのボタンに表示される理由を確認します。キューのコメントがない、CURRENTと盤面のミノが違う、消去されていない完成行がある、といった局面では表示されません。

リプレイを読み込めない

2人対戦の.ttrmファイルか確認してください。読み込めない場合は、画面に失敗の理由が表示されます。

画像を読み込めない

画像がクリップボードにコピーされていること、盤面のマス目に沿っていることを確認します。余白や文字を減らして再度範囲選択してください。

ツリーが消えた

1ページ目コメントの #TREE=... が残っているか確認します。削除後に保存や共有を行った場合、元のツリーデータは復元できないことがあります。

設定が戻った

設定はブラウザ内に保存されます。キャッシュやサイトデータの削除、別ブラウザ・別端末では引き継がれません。

共有相手と見え方が違う

共有URLを開き直し、キックテーブル、「上部の空白行を省略」、ツリーモードなどが意図どおりか確認してください。
